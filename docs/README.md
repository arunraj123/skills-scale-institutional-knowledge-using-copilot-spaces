# OctoAcme Project Management Documentation

Welcome to OctoAcme's project management process documentation. This README provides an overview of our approach and links to detailed guidance for each phase of project delivery.

## Overview of OctoAcme Project Management

OctoAcme runs projects using five core principles:

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has a named Project Manager (PM) and Product Lead
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning

## Core Roles

- **Project Manager (PM)**: Coordinates delivery, schedules, risk, and communication
- **Product Manager (PdM)**: Defines outcomes, prioritizes the backlog, and measures success
- **Developers**: Implement features, collaborate on design, and deliver quality-tested work
- **QA / Testing**: Validate quality and acceptance criteria
- **Stakeholders**: Provide input, guidance, and approvals

## Project Lifecycle

All OctoAcme projects follow this five-phase lifecycle:

```text
[Initiation] → [Planning] → [Execution] → [Release] → [Retrospective]
```

## Summary of the OctoAcme Project Management Process

OctoAcme's project management approach emphasizes a lightweight, cross-functional workflow that keeps customer value at the center. Projects are initiated by validating the problem, aligning stakeholders, and creating a clear one-pager. Planning turns approved work into a backlog with milestones, dependencies, and acceptance criteria. Execution focuses on recurring delivery rhythms, quality checks, and proactive blocker management. Release processes standardize deployment readiness and rollback planning. Finally, retrospectives capture lessons learned and convert them into concrete improvements for the next cycle.

This creates a repeatable system that balances speed, clarity, risk management, and continuous improvement while keeping teams aligned around outcomes.
